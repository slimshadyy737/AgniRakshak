# Contributing to AgniRakshak

Thank you for reviewing **AgniRakshak**! We welcome contributions, feature suggestions, and bug reports.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-org/AgniRakshak.git
   cd AgniRakshak
   ```
2. Double-click `run_agnirakshak.bat` to automatically set up dependencies and launch the application.

## 🧪 Testing Guidelines

- Python Backend Tests: `pytest`
- React Frontend Build: `npm run build` inside `frontend/`
